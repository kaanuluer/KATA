Global Agent Bureau

Know the agent before the payment goes through.

Global Agent Bureau is an independent agent bureau. Participants register agents, check signed intents, inquire with a purpose code, and report incidents. The checks are powered by KATA — Know And Trust Agents. A valid identity is not the same thing as a valid action.

    The principal who signed the delegation and the intent.

  3. 03 What was it authorized to do?

    Purpose, ceiling, currency, merchants, and expiry.

  4. 04 Does this behavior match?

    The payment is checked against that signed record.

Stress test

SYNTHETIC TEST DATA – not real customers

This is the latest synthetic stress test of the trust score: 10,000 synthetic agents and 100,000 synthetic transactions over 90 days. Against adaptive attackers, 73% of attempted fraud dollars are stopped and $0.71M is executed. When attackers do not know the rules, 78% is stopped and $0.68M is executed. Legitimate agents denied at day 90 are 0.15% and 0.16%. Tables and charts are on the Simulation page. Global Agent Bureau is an agent bureau. Learn more at globalagentbureau.com.
