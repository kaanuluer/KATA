Global Agent Bureau

Know the agent before the payment goes through.

Global Agent Bureau is an independent agent bureau. Participants register agents, check signed intents, inquire with a purpose code, and report incidents. The checks are powered by KATA — Know And Trust Agents. A valid identity is not the same thing as a valid action.

Agent identity

The actor has a name before it has a payment.

An agent is registered with a provenance. The public sample is shopper-01, authorized by K. Uluer. Assurance can be key-bound, operator-verified, or unverified. When a trust score is kept, it belongs to the agent. Individuals are not scored.

Authorization

The principal signs the intent. The payment has to match it.

The signed record names the purpose, the ceiling, the currency, the merchants, and the expiry. KATA checks the proposed payment against that record. A registered agent can still be outside what was signed.

Dispute evidence

A dispute keeps the signed record with the agent.

Evidence is the intent, the payment, and the outcome, linked to the agent. A report that is not linked to an agent is rejected. Participants can inquire for dispute resolution with a purpose code.

SYNTHETIC TEST DATA – not real customers

This is the latest synthetic stress test of the trust score: 10,000 synthetic agents and 100,000 synthetic transactions over 90 days. Against adaptive attackers, 73% of attempted fraud dollars are stopped and $0.71M is executed. When attackers do not know the rules, 78% is stopped and $0.68M is executed. Legitimate agents denied at day 90 are 0.15% and 0.16%. Tables and charts are on the Simulation page. Global Agent Bureau is an agent bureau. Learn more at globalagentbureau.com.
