Global Agent Bureau

Know the agent before the payment goes through.

Global Agent Bureau is an independent agent bureau. A participant can see who the agent is, what a principal signed, and whether this payment matches. The checks are powered by KATA — Know And Trust Agents. A valid identity is not the same thing as a valid action.

Explainer

How the check works

73.5 seconds, silent, with captions on the picture and an English text track in the player. It stays paused until you press play.

  1. 01Who is the agent?

    Identity and provenance of the agent that wants to act.

  2. 02Who authorized it?

    The principal who signed the delegation and the intent.

  3. 03What was it authorized to do?

    Purpose, ceiling, currency, merchants, and expiry.

  4. 04Does this behavior match?

    The payment is checked against that signed record.

Agent identity

The actor has a name before it has a payment.

An agent is registered with a provenance. The public sample is shopper-01, authorized by K. Uluer. Assurance can be key-bound, operator-verified, or unverified. When a trust score is kept, it belongs to the agent. Individuals are not scored.

Authorization

The principal signs the intent. The payment has to match it.

The signed record names the purpose, the ceiling, the currency, the merchants, and the expiry. KATA checks the proposed payment against that record. A registered agent can still be outside what was signed.

Dispute evidence

A dispute keeps the signed record with the agent.

Evidence is the intent, the payment, and the outcome, linked to the agent. A report that is not linked to an agent is rejected. Participants can inquire for dispute resolution with a purpose code.

Linked

Chargeback on shopper-01

The signed ceiling, the CAD 1,300 payment at techstore.example, and the outcome stay on the same agent.

Rejected

Report with no agent

An unlinked report is not evidence. It does not enter the record.

Purpose code required

Dispute resolution is one purpose. The inquiry does not change the score.
